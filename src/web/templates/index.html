About This Project

This is a thesis project for automated detection and classification of rugby plays from video footage.

Play Categories

  • Scrum: Set-piece where forwards pack together
  • Line: Lineout throws from the sideline
  • Other: All other plays (open play, kicks, tries, etc.)

How It Works

  1. Select a trained model from available options
  2. Choose a video from the library or upload a new one
  3. Adjust detection parameters to fine-tune results
  4. Ejecutar el análisis y revisar las jugadas detectadas en un timeline
